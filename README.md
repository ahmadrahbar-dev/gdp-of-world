# gdp-of-world# 🌍 World GDP Explorer

A modern, interactive web application that displays real-time GDP data of all countries worldwide. Built with React.js and powered by World Bank Open API.

## 🚀 Features

- 📊 **Live GDP Data** - Real-time GDP figures from World Bank API
- 🔍 **Search Functionality** - Instantly find any country's GDP
- 🏆 **Top 10 Economies** - Quick overview of world's largest economies
- 🌙 **Modern UI** - Premium dark theme with smooth animations
- 📱 **Fully Responsive** - Works perfectly on all devices
- ⚡ **Fast Performance** - Optimized React components

## 🛠️ Tech Stack

- **React.js** - Frontend framework
- **CSS3** - Custom styling with modern effects
- **World Bank API** - GDP data source
- **Vite** - Build tool.
